# Sales Data Analysis Project

## Project Overview
This project analyzes sales data to identify revenue trends, product performance, and regional performance.

## Tools Used
- **Python:** Data generation, data cleaning, and analysis.
- **SQL:** Sales analysis and database queries.
- **Power BI:** Interactive sales dashboard.
- **Pandas & Matplotlib:** Data analysis and visualization.

## Project Structure
- `data/` — Sales dataset and SQL database.
- `scripts/` — Python scripts for data generation, analysis, and database loading.
- `sql/` — SQL queries for sales analysis.
- `powerbi/` — Power BI dashboard and analyzed data.
- `reports/` — Generated charts and reports.

## Key Analysis
- Revenue by product.
- Revenue by region.
- Monthly revenue trends.
- Product performance and profitability.

## Dashboard
The Power BI dashboard presents sales performance through charts and KPI cards for revenue and profit.

## Note
The dataset was synthetically generated for educational and portfolio purposes.
